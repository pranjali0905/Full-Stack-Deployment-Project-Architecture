# 🛍️ Nexa Store — Modern E-Commerce Website

Nexa Store is a modern, responsive e-commerce web application built using **React and Vite**. It provides a smooth shopping experience with product browsing, search, category filtering, sorting, wishlist functionality, and a shopping cart.

## ✨ Features

- 🛒 **Product Catalog** — Browse a collection of products.
- 🔍 **Search Products** — Quickly find products by name.
- 🗂️ **Category Filtering** — Filter products by category.
- ↕️ **Product Sorting** — Sort products based on available options.
- ❤️ **Wishlist** — Save your favorite products.
- 🛍️ **Shopping Cart** — Add and manage products in your cart.
- 💾 **Local Storage** — Cart data persists across page refreshes.
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile screens.
- 📄 **Product Details** — View individual product information.
- ✉️ **Newsletter Form** — Interactive newsletter subscription demo.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Routing:** React Router
- **Icons:** Lucide React
- **Styling:** CSS3
- **Storage:** Browser Local Storage
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd nexa-store-capstone
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Build for Production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
